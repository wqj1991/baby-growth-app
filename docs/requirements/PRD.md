# 宝宝成长记录 APP 需求文档（PRD）

## 1. 产品核心定位
一款无自建服务器、全家实时协同、相册规则可定制、轻量省空间的宝宝成长记录 APP。

### 1.1 核心原则
- APP 独立专属相册，内置拍照/视频自动存入该相册并本地留存。
- 手机原有相册素材上传时，仅备份到夸克网盘，永不删除本地原图。
- 影像浏览采用双模式：缓存在线预览 + 手动下载保存到本地。
- 育儿数据支持一键记录（奶量、大小便、睡眠等）。
- 依托夸克网盘实现全员实时同步，一人记录全家实时可见。
- 本地存储可控，按需缓存、按需下载，不冗余占用空间。

## 2. 核心功能需求

### 2.1 影像拍摄与相册规则
- 自动创建 APP 独立专属宝宝相册文件夹。
- APP 内直接拍照/录像：自动保存至专属相册，并实时同步上传夸克网盘。
- 从手机系统相册选择上传：仅上传网盘，本地原图完整保留、不删除、不改动。
- 夸克网盘按月龄/日期自动分类归档，云端永久备份。

### 2.2 影像浏览双模式

#### 2.2.1 缓存在线查看
- 浏览网盘照片/视频时，自动加载压缩缓存缩略图或低清预览。
- 缓存支持智能管控：自动过期清理、手动一键清空缓存。
- 浏览全程无需完整下载原文件，可快速滑动查看全部影像。

#### 2.2.2 手动下载保存
- 支持单张/多选照片与完整视频的手动下载。
- 默认保存到 APP 专属相册，用户可在下载时或设置中改选保存路径（如系统相册）。
- 仅在用户主动操作时才落地本地文件，禁止自动下载原图/原视频。

### 2.3 育儿数据记录
- 奶量：母乳/奶粉/辅食、摄入量、喂养时间、备注。
- 大小便：小便/大便快速打卡，记录性状与次数。
- 健康台账：睡眠、体温、疫苗、体检、用药等。
- 文字数据轻量化存储，日志与配置数据加密存储到夸克网盘。

### 2.4 家庭成员实时协同
- 提供专属家庭空间，绑定一个夸克账号（共享登录）。
- 拍摄、上传、文字记录统一实时同步到夸克网盘。
- 成员重新进入页面、下拉时间线或定时同步时获取最新内容。
- 记录操作人标签（家庭成员身份），用于区分记录来源。

### 2.5 夸克网盘同步与存储（无服务器）
- 全部云端数据与多端同步依赖夸克网盘，无需自建服务器。
- 网盘能力范围限定为：文件上传/下载/目录管理。
- 用户进入 APP 时自动拉取最新配置，并按配置拉取最新内容。
- 文字日志、结构化数据、原图视频统一分类存储于网盘。
- 支持仅 WiFi 上传大文件。
- 更换设备并登录同网盘账号后，可在线查看全部历史内容。

### 2.6 缓存与存储管理
- 预览缓存智能清理，支持自定义缓存上限。
- 默认缓存上限为 2GB，默认自动清理周期为 7 天。
- 低电量时不暂停预加载。
- 相册内容分类管理：实拍本地内容、网盘缓存内容、手动下载内容。
- 无后台静默下载、无冗余副本，严控存储占用。

## 3. 页面结构与层级架构
底部固定 4 个 Tab：首页、快速记录、数据统计、我的。

### 3.1 启动页
- 权限授权：相机/相册/网络/存储/通知。
- 夸克网盘绑定（共享账号登录）+ 家庭空间初始化。
- 自动生成 APP 专属宝宝相册文件夹。
- 进入主界面。

### 3.2 Tab1 首页（成长实时动态）
- 宝宝月龄、今日喂养/起居数据概览。
- 全家实时动态信息流（照片、视频、文字）。
- 影像默认缓存低清在线预览。
- 单条影像操作：缓存查看 / 下载保存到本地相册。
- 快捷拍照、快速打卡入口。

### 3.3 Tab2 快速记录
- 拍摄模块：拍照/录像 -> 存入专属相册并同步网盘。
- 本地上传模块：选择手机相册素材 -> 上传网盘且保留本地原图。
- 育儿记录模块：奶量/大小便/睡眠/健康快速录入。
- 提交后同步到网盘，成员可通过重进/下拉或定时同步查看更新。

### 3.4 Tab3 数据统计
- 喂养、排泄、睡眠数据图表统计。
- 健康档案、身高体重、疫苗体检台账。
- 历史记录检索与时间筛选。

### 3.5 Tab4 我的
- 家庭空间管理：共享账号说明、成员标签管理。
- 夸克网盘：同步设置、文件管理、空间查看。
- 相册管理：专属相册查看、下载目录设置。
- 缓存管理：自动清理、手动清空、容量限制。
- 宝宝档案编辑。
- 系统设置、消息提醒。

## 4. 交互逻辑与业务规则

### 4.1 拍摄与上传规则
- 内置相机拍摄：自动存 APP 专属相册 + 上传夸克网盘。
- 手机相册上传：仅备份网盘，本地原图完整保留。

### 4.2 影像浏览规则
- 动态/相册列表默认加载云端压缩缓存进行在线浏览。
- 用户可在“仅浏览”和“下载保存本地”之间自主选择。
- 缓存为临时预览用途，支持自动过期清理和手动清空。

### 4.3 实时同步规则
- 任意成员新增拍摄/上传/文字记录后，数据同步到夸克网盘。
- 成员重新进入页面或下拉时间线时触发刷新并拉取最新内容。
- 在无操作场景下，客户端每 10 分钟执行一次自动同步。

### 4.4 断网适配规则
- 无网络时：可正常拍照存专属相册，文字本地暂存。
- 无网络时禁用：网盘浏览、本地相册上传。
- 恢复网络后：自动补传未同步内容，并刷新缓存与动态。
- 同一条记录多人离线修改后恢复网络：采用最后写入覆盖（Last Write Wins）。

## 5. 一致性检查结论
- 独立专属相册可实现实拍内容本地集中管理。
- 本地上传不删除原图，满足用户资料保护诉求。
- 影像双模式（缓存预览 + 手动下载）可平衡体验与存储。
- 无服务器架构下，夸克网盘可承载同步与备份主链路。
- 家庭协同形成记录、同步、查看闭环。
- 缓存可配置可清理，长期使用不易臃肿。
- 现有逻辑无明显冲突，具备开发落地可行性。

## 6. 开发落地关键备注
- 所有网盘音视频/图片默认仅加载预览缓存，禁止自动下载原文件。
- 下载行为必须由用户主动触发；默认保存到 APP 专属相册，并允许用户改选下载路径。
- 影像必须按三类管理：本地实拍、云端缓存、手动下载。
- 必须提供缓存配置项：最大缓存容量、自动清理周期，默认值分别为 2GB 和 7 天。
- 夸克网盘仅使用文件上传/下载/目录管理能力；通过“进入自动拉配置 + 下拉刷新 + 10 分钟定时同步”获取最新内容。
- 日志和配置数据需加密后再存入夸克网盘。
